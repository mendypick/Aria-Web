# Aria Web

Marketing site for Aria, a dating app for Black singles with high standards.

## Install

```bash
npm install
```

## Run locally

```bash
npm run dev
```

The site opens at http://localhost:5174/.

## Build

```bash
npm run build
```

The static site is written to `dist`. Preview that build with:

```bash
npm run preview
```

## Deploy

Pushing to `main` runs the GitHub Pages workflow in `.github/workflows/pages.yml`. Enable GitHub Pages for the repository and set the source to GitHub Actions.
